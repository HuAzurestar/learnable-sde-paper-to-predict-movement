# PIRC-17 public review artifact interface

This interface is preparation, not completed evidence cards, manuscript,
scientific qualification, an authorship decision or human acceptance. Actual
formal predictions, complete scoring, independent saved-output audit and
public export must finish before their real results enter the paper workflow.
Use only the immutable PUBLIC review cards and an independently recorded
content SHA256. A self-consistent file hash alone is not source authority.
Never use private trajectory arrays, model checkpoints or legacy NEX326
single-process numbers as substitutes for this sealed multitime study.

From the TSDE repository root, in an environment containing Matplotlib,
NumPy and Pillow:

```powershell
python -m scripts.aggregate_pirc17 --cards PUBLIC-CARDS.json --sha256 CONTENT-SHA256 --output-directory artifacts/pirc17-review/tables
python -m scripts.plot_pirc17 --cards PUBLIC-CARDS.json --sha256 CONTENT-SHA256 --output-directory artifacts/pirc17-review/figures
```

The table bundle contains 16 CSVs, including all 90 named comparisons, 120
accuracy summaries, 480 scoring-time rows, 22 arms/36 slots, 13 raw factors/35
variants, ten independently fitted terrain ownership records, 84 mechanism
summaries, full numeric/score and variance witness inventories, 38 scientific
kernel-cost subjects, 38 replays, 165 runtime trials and 30 condition summaries.
Required/excluded method slots remain separate from terrain conclusions.

The figure bundle contains 16 figures in both PNG and vector PDF: method and
terrain paired contrasts separately for each origin mode; terrain time
profiles and mechanism availability for all three modes; isolated cold/warm
runtime; declared terrain dimensions; scientific dispositions; and recorded
kernel costs. `figure-inputs.json` preserves the exact plotted public data,
units and scopes. All registered coverage levels remain in the tables; time
profile figures display the declared 95% region. Line segments between the
four original scoring times guide the eye, not new intermediate scores.

Rendering does not fit, predict, resample, run tests, recalculate quantiles or
bootstrap intervals. Primary intervals are the original simultaneous
within-family intervals; secondary origin modes remain descriptive. Missing
metrics are not zero, successful-subset accuracy is not used, failed trials
stay counted, and warmup is not included in latency quantiles. Recorded
ordinary kernel times are not isolated latency or total project cost.
Mechanism availability percentages are inventory counts, not effect sizes.
Every image remains a review candidate; no human acceptance is granted.

Each bundle uses content/source-code hashes, and the figure identity also
records rendering-library versions, the FreeType version and font hash.
PNG/PDF byte equality is tested within the same recorded environment; it is
not promised across arbitrary library/font upgrades. PDF creation dates are
omitted. Existing complete figure bundles reuse hash-bound images; a missing
image is regenerated alone. Corrupted or different existing outputs are
rejected, not overwritten. There are no blocking writer locks, restoration
gates or whole research-history scans.

For synthetic demonstrations use `--software-fixture`: the fixture flag is
bound into the output identity and gives the images an explicit software
watermark. Such outputs are not empirical results. No real PIRC-17 result
bundle or manuscript is generated by the software tests below:

```powershell
python -m pytest tests/test_pirc17_tables.py tests/test_pirc17_figures.py tests/test_pirc17_gate_integrity.py -q
python -m scripts.check_public_release
```

Paper language/template and real authorship must be confirmed separately.
Full editable manuscript, review PDF, claim-to-evidence review, recorded
accepted revisions and actual final human acceptance remain required.
